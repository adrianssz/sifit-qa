# SIFIT — Documentação de Qualidade de Software

Repositório do trabalho individual da disciplina de Extensão em Qualidade de Software, destinado à documentação de requisitos e testes manuais do sistema SIFIT.

## Objetivo

Aplicar os conhecimentos de qualidade de software por meio da análise das funcionalidades do SIFIT, do planejamento e da execução de testes manuais e do registro dos resultados obtidos.

## Documentação prevista

- Análise de requisitos.
- Plano de testes.
- Cenários e casos de teste.
- Relatório de bugs.
- Relatório dos testes executados.
- Evidências dos testes.
