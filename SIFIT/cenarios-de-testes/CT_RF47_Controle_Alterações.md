 CENÁRIO 47: CONTROLE DAS ALTERAÇÕES DOS COLEGAS NO AMBIENTE COMPARTILHADO

 CASO DE TESTE 01: VERIFICAR O HISTÓRICO DE ALTERAÇÕES NO GITHUB

| ID        | DESCRIÇÃO |
| --------- | --------- |
| CT47-CT10 | Verificar se o ambiente compartilhado permite acompanhar e identificar as alterações realizadas pelos integrantes da equipe no repositório GitHub. |

| PRÉ-CONDIÇÕES |
|---|
| O usuário deve possuir acesso ao repositório compartilhado da equipe no GitHub. |
| Devem existir alterações registradas pelos integrantes da equipe no histórico do repositório. |

| PASSOS |
|---|
| ACESSAR o GitHub. |
| ACESSAR o repositório compartilhado SIFIT-QA. |
| ACESSAR a pasta SIFIT. |
| LOCALIZAR a pasta cenários-de-testes. |
| ACESSAR o histórico de alterações (History). |
| VERIFICAR se os commits realizados pelos integrantes da equipe são apresentados. |
| OBSERVAR os responsáveis pelas alterações, as datas e as mensagens dos commits. |
| VERIFICAR se é possível consultar os detalhes das alterações registradas. |

| CRITÉRIOS DE PROTEÇÃO |
|---|
| O GitHub deve permitir consultar o histórico de alterações do repositório, identificando os responsáveis, as datas e as descrições dos commits realizados pelos integrantes da equipe. |
