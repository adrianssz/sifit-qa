 CENÁRIO 46: APLICATIVO

 CASO DE TESTE 01: ACESSAR E CONSULTAR MENU APLICATIVO

| ID        | DESCRIÇÃO                                                                                                                        |
| --------- | -------------------------------------------------------------------------------------------------------------------------------- |
| CT46-CT01 | Verificar se o menu Aplicativo permite acessar e consultar as informações e opções disponíveis no sistema SIFIT. |

| PRÉ-CONDIÇÕES |
|---|
| O usuário deve estar autenticado no sistema SIFIT e possuir permissão para acessar o menu Aplicativo. |

| PASSOS |
|---|
| ACESSAR o site SIFIT. |
| REALIZAR o login no sistema. |
| ACESSAR o Dashboard. |
| LOCALIZAR e CLICAR no menu Aplicativo. |
| VERIFICAR se a página de Aplicativo é exibida corretamente. |
| OBSERVAR as informações apresentadas na tela. |
| VERIFICAR se existem opções de consulta ou visualização das informações disponíveis. |

| CRITÉRIOS DE PROTEÇÃO |
|---|
| O sistema deve permitir o acesso ao menu Aplicativo e apresentar corretamente as informações disponíveis, possibilitando a consulta conforme as funcionalidades implementadas. |
